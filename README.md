# PyGAVFE General and Versatile File Editor

## Description
GAVFE or the "General and Versatile File Editor" is a command-line or terminal file editor that aims
to provide as an editor for many file types. It was started by me around July of 2026 because I was bored
and didnt know what I want to code in Python. 

## Story of PyGAVFE
I'm kind of a beginner and I wanted to learn web building, data structures and algorithms, or other
python modules like numpy and pandas though I was too lazy to learn them then. I decided that 
"hmm, nano and vim are cool terminal text and code editors. Why not make my own?" I thought. Then
I started the project on Python (which is why this repo is called PyGAVFE).

## File Type Support
GAVFE *currently* supports the following file types:
  * Files types that contain regular plain text (eg. .txt, .md, .py)

Future file support:
  * Bytecode files (eg. .bin and via builtin hex editor)
